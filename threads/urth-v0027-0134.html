1999-07-12 Jonathan Laidlow #

Asks for help with a technical problem: saving the Urth and Whorl digest archives as plain text in a word processor keeps producing HTML code that clutters the file. Describes downloading volumes up to 25 to bind them as a bookshelf collection and asks how to strip the HTML codes.
questions

Hello folks,

I've grown used to thinking that I'm quite computer literate. Apparently not. I like to download and format the Urth and Whorl digests using a Word processor so that I can bind them together and put them on my bookshelf. I have up to volume 25 and as I wanted to refer to the fight I started in volume 26 I tried to download it. Now no matter how hard I try to save it in text only format it still actually saves it in html format - which then produces a zillion codes when I load the file into Word. If I could even find a way of deleting all html codes I'd be happy.

Can any of you explain to me where I'm going wrong? Best to reply to me off-list....

Jonathan
