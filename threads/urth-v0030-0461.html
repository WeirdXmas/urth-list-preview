2001-05-29 Kevin J. Maroney #

Informs readers that a widely circulated SULFNBK.EXE virus warning is partly inaccurate, since the file is a standard Windows component and only copies outside the command directory are likely infected. Gives the practical test of file location and points to an antivirus vendor's advisory for details.
informs

The SULFNBK.EXE warning is not accurate.

There *is* a virus/worm which propogates through corrupted copies of the SULFNBK.EXE file. However, this file is a standard part of the Windows installation. If you have a copy of SULFNBK.EXE in the windows\command directory, it is almost certainly not infected. If you have a copy anywhere else, it probably *is* infected and should be deleted.

<http://www.symantec.com/avcenter/venc/data/sulfnbk.exe.warning.html> has more information.
