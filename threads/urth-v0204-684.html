2002-04-22 Matthew Malthouse #

Gives step-by-step instructions for turning off styled text in Eudora 5.1 so messages send as plain text, responding to a poster who asked for help with the setting. Offers the menu path for both PC and Mac versions of the program, with no reference to Wolfe's books.
answers

For Eudora 5.1. In the menu bar go to tools...

Select the Options... (on a PC) or Settings... (on a Mac) item.

In the panel that comes up on the left hand side select "Styled Text"

Of the options then presented select "Send plain text only".

HTH

Matthew
