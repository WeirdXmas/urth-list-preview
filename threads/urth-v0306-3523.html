Themes: Memory and forgetting

2003-06-23 Rex Gatch #

Reports a television program about a head-injured patient who kept old memories but could not form new ones, yet learned table tennis, suggesting motor skills survive memory loss. Offered as possible help for understanding Latro's memory loss in the Latro books, with a reference to the film Memento.

If its any help I saw a program on Brain injuries a while ago. One of the patients had suffered a head injury. He retained his memories = from before the accident but couldn't form any permanent new ones. So far so memento, but the weird thing was that he had learned to play = table tennis at the hospital even though he had never played before the = injury. Which seemed to imply that he could learn motor skill related = stuff.
Ambergris
