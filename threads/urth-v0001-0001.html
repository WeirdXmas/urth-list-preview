URTH list is now open!

Urth list · 1 messages · 1997-04-05 to 1997-04-05

1997urthRanjit Bhatnagar

1997-04-05 Ranjit Bhatnagar #

Announces that the URTH mailing list is open for discussion of Wolfe's Book of the New Sun and explains how to subscribe and which list to use for Long Sun material. Gives the subscription commands, archive and web page locations, and the rule that messages go to WHORL or URTH but not both.
informs

The URTH mailing list is now open! Its primary purpose is the discussion of Wolfe's Book of the New Sun.

To subscribe to URTH, send "subsingle" to [email]
If you want a daily digest, send "subscribe" instead.

Archives of the URTH list and background information on
Wolfe and the New Sun will be found on the web at

http://moonmilk.volcano.org/urth/

If you have suggestions for web links, book reviews, or
anything else that should go on this page or the
corresponding Whorl page
(http://moonmilk.volcano.org/whorl/), please send 'em
directly to me: [email]

OK, here's how it works:

If it has anything to do with the Book of the Long Sun, send it to WHORL. ([email])

If it's Wolfe, but not related to the Long Sun, send it to URTH. ([email])

Please do not send the same message to both lists. If it has something to do with the Long Sun, it belongs on WHORL; otherwise, URTH. I expect that a lot of us will be
subscribing to both lists, so double messages would get to be annoying.

In fact, it may turn out that almost everybody subscribes to both lists -- if that's the case, I'll merge 'em into one list. We'll wait a few months and see how it turns out.

Remember, if you subscribe to only one list, you can always catch up on the other list by reading the archives:

http://moonmilk.volcano.org/urth/archives/
http://moonmilk.volcano.org/whorl/archives/

However, if you want to contribute to either list, you must subscribe to it first. (This is to discourage junk-mailers.)

Questions? Suggestions? Hate mail? [email].
