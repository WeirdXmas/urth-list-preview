Asks list members to supply page citations for a compiled list of Trivigaunte and Flier terms from The Book of the Long Sun, and invites additions to the glossary. Names the specific terms, such as 'ishsh, Betifham, Boraz and Canna, to be located in the text.

Having rounded up all the words and definitions (for LS-2) that we were able to come up with, I've still managed to misplace the page citations for all the Trivigaunte and Flier terms. If anybody has them I'd appreciate it if you could post them. (And if there are any Trivigaunte/Flier terms I've left out, this is the last chance to bring them to my attention so I can add them.)
