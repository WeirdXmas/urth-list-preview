MIME format garbage

Urth list · 1 messages · 2000-08-14 to 2000-08-14

2000-08-14 A Aramini #

Asks the list how to stop his posts from showing duplicated, garbled MIME content that repeats the message and wastes space. Describes the problem as a technical mail-formatting issue, with the post itself containing both plain-text and HTML versions of the same message.
