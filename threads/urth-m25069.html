The thread: Subscribers asked whether list mail was being diverted into Gmail spam folders, with Gwern Branwen raising the issue after Yahoo-sent messages from Marc Aramini kept landing there. Dimitar Nikolov offered a Gmail filter workaround, which António Pedro Marques said was not enough since messages still disappeared partway through reading. 2014-04-28 Dimitar Nikolov replying to Fred Kiesche #

Explains that Gmail's spam filter has grown more aggressive and is diverting list messages, and gives a fix: create a Gmail filter so messages to the list address are never marked as spam. Responds to Fred Kiesche's complaint that Gmail keeps dumping list mail into the spam folder and offers a practical workaround, with no Wolfe content.
informs

Long time lurker here. I've noticed this too, and unfortunately it looks like gmail's spam filter has become more aggressive, since this has been happening with other messages for me. The solution is to set up a filter from Settings > Filters, such that messages sent to [email] are never marked as spam.

Hope this helps.

Best,
Dimitar
