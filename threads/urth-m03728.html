The thread: Dan'l Danehy-Oakes invited list members to help build content on the WolfeWiki, which he said was nearing critical mass, and Matthew Groves offered help and flagged a wrong Pirate Freedom date in the standalone novels list. 2007-07-04 Dan'l Danehy-Oakes replying to Matthew Groves #

Describes the plan for a collaborative Wolfe reference project, saying the work is evolving and starting with basic factual content such as editions sections under each book and the contents of rare collections. Replies to Matthew Groves, who offered help and noted that the Pirate Freedom publication date is wrong in the standalone novels list.
informs

It's evolving as we go. Mo can say more than me, he's the captain of this ship. I'm just trying to stoke the boilers a bit.

Right now, we seem to be just getting in the basic factual content. One thing I initiated is putting an "editions" section under each book (I'm not sure if they're there for the books I haven't worked on), so anyone having an edition not so far listed is particularly asked for information.

Also, neither Mo nor I has any of the rarer collections
("Young Wolfe," "Bibliomen,' etc.), so anyone who has
those and can enter the contents -- it would be greatly
appreciated.

Then once that's done, the fun stuff begins -- we can
start working on plot summary, interpretation, relations to other works, references to other works (including
other writers), etc. Though I guess the one thing does
not have to be finished before the other starts.

That appears to be fixed now.

2007-07-04 Mo Holkar / UKG replying to Dan'l Danehy-Oakes #

Describes the status of a shared wiki project: the bibliography and resource list has been set up, but the poster wants more participants and agreed objectives before a task list. Explains that a main aim is a wiki capturing list interpretations, such as points raised about the story Unrequited Love, for later reference.
informs

It'd be great to have you involved! There's certainly plenty to do, even in the current limited scope.

I prefer to think of myself as the shipowner in a remote (and pleasantly heated) office...

At the moment we've just been working on getting the bibliography / list of resources up and established.

My feeling is that it needs a few more people involved, and a consensus about what the project's objectives are, before we can generate a proper task list.

(FWIW, my own main objective would be to have a place to capture the main interpretations, explanations, theories, debates etc from this list in a more convenient form than an email archive provides. So, for example, we've recently had a bunch of good stuff posted about the new story Unrequited Love -- I'd like to see a wiki page summarizing the various interesting points made, so that when I come to read the story again in the future, I have an easy recourse to what people have said about it.)

There are probably other such errors, though, as we typed in a good deal of data pretty quickly, so if anyone spots anything do say (or dive in and fix it yourself),

best,

Mo
