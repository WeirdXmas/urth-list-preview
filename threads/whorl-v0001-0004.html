Announces that the list archives are now online and that a names list will summarize list discussions of Whorlish names, and invites contributions such as a list of questions and conundrums. Gives examples like how big the whorl is and where Quetzal came from, plus contact addresses for list and web matters.
informs

Some announcements related to the WHORL mailing list and web pages:

* The ARCHIVES are now available on the web page. There's not much now, but (if I got my programs working properly) every posting to the mailing list will appear on the web page as well.

http://moonmilk.volcano.org/whorl/archives/

* I'm also keeping a NAMES LIST, a handy reference to discussions of Whorlish names. Anything relevant that appears on the mailing list will get summarized there when I have time.

http://moonmilk.volcano.org/whorl/names.html

* There's a lot more that could be done with the web page. Suggestions and contributions are welcome. For instance, I'd like to have a list of questions and conundrums, with links to mailing list discussions relevant to those questions. Like, how big is the whorl? Where did Quetzal come from? And so on. Also, if you have found or created any artifacts, images, web pages, links, etc., let me know and I'll put 'em on the Whorl Web.
