2010-12-09 Son of Witz replying to Lee Berman #

Argues that a web forum beats the mailing list for following discussions, since the list's web interface forces users to leave it to post while a forum allows notifications on threads. Responds to Lee Berman's remark about setting email to block the list and using the web archive sorted by thread, subject or author, adding that he has 4000 unread list messages.
supports

Me too. Hence 4000 unread messages now in my daily backup. :)

The web interface is ok, but you have to jump out of it if you want to post. Plus, with a forum you can subscribe to notifications. If you ask a question, you can set it so that you don't miss an answer someone provides maybe two years later.
