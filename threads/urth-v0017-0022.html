1998-07-16 Mark Millman #

Apologizes in advance for an automatic vacation reply that Mark Millman's mail program will send to anyone who writes him during a week away. Explains that the program sends only one reply per correspondent, so recipients will see the note just once; it has no bearing on Wolfe or the books.
chats

Folks,

I'm writing to apologize in advance for a pointless note that I'll be sending to some of you. I'm going on vacation for a week, and have (I hope) set my mail program to generate an automatic response to all incoming mail. The program I'm using, however, won't allow me to exclude certain classes of message, so that anyone who writes to me will get the response whether they should or not. I have, however, set the device to generate only one response per correspondent, rather than one response to each message. So I'm sorry for sending you the pointless note, but at least you'll only see it once.

Mark Millman
