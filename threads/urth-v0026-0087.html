1999-05-04 Jonathan Laidlow #

Announces an update to a web page listing Gene Wolfe's unpublished short fiction, now adding titles from before 1990 and a list of this year's publications, and asks readers to report errors. Shares the site address and a link to the wider Ultan's Library Wolfe resource.
informs

Just to let you know that the unpublished short fiction web page has had a rushed update today. It now features titles for short fiction prior to 1990, and Robert's list of this year's publications.

If you spot any mistakes, please let me know.

It can be found at http://members.tripod.co.uk/laidlow/wolfshort.htm

J.
