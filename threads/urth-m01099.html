Themes: Memory and forgetting

2005-07-06 Malcolm McGugan #

Shares a Microsoft research link about a wearable camera that records images of daily life, comparing it to Severian's perfect memory in the Book of the New Sun. Suggests future devices could add audio and sensor data to create a full life-logging tool, joking that such logs could be the blogs of the future.
informs

http://research.microsoft.com/sendev/project_sensecam.aspx

Want to have a memory like Sev?
Want to record every day and play it back and forwards
again and again any way you want?
Right now it's only 2000 images a day, but AV feed and
parametrics like GPS, environment, etc. can't be too
far off. Then we can all have a true "life-logging"
tool. Blogs of the future...
