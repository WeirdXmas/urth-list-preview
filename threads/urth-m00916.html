2005-01-11 Kieran Mullen #

Asks whether the list should set up a wiki page serving as a FAQ for The Wizard Knight books, explaining that readers could add and edit questions collaboratively. Notes the concern that a wiki needs trustworthiness because anyone can alter others' text.
questions

Is it worth setting up a Wiki page for a FAQ on the Wizard Knight books?

For those of you who don't know, Wiki is a system which allows the viewers of the webpages to edit and add to them. That way we can dynamically add to a list of questions. However, it requires a certain amount of trustworthiness since anyone can trash anyone else's prose.

Kieran Mullen
